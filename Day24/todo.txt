Следующие шаги практики — попробуй сам, прежде чем подглядывать
Задание 1. Фильтр по payload. Тот же запросный вектор, но искать только внутри 05_finance_investing.pdf. Предскажи до запуска: какой score будет у первого результата — выше или ниже 0.87?
Задание 2. Проверка pre-filtering. Сравни два подхода: (а) query_points с фильтром и limit=3; (б) query_points без фильтра с limit=20, потом отфильтруй результаты в Python вручную. Совпадут ли топ-3? Это руками покажет разницу pre- vs post-filtering из плана.
Задание 3. Upsert по существующему ID. Возьми чанк 01_machine_learning_chunk_0, измени ему payload (например page: 99), сделай upsert по тому же UUID5 — и проверь, что count остался 36, а payload обновился.
Задание 4. set_payload. Пометь все чанки одного документа флагом {"outdated": true} без пересылки векторов.
Задание 5. Delete по фильтру + сценарий «документ обновился». «Удали» 01_machine_learning.pdf из индекса (delete по фильтру source == ...), проверь count=33, потом за-upsert'ь его обратно из файла — это и есть прототип точечной переиндексации.
