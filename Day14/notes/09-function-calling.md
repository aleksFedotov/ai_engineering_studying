# Function calling (tools)

Function calling — механизм, при котором модель не отвечает текстом, а просит вызвать функцию: возвращает JSON с именем функции и аргументами. Сам вызов делает НАШ код, модель его не выполняет.

Схема из лекции:
1. В запрос передаём описания функций (tools): имя, описание, JSON-схема параметров.
2. Модель решает: ответить текстом или вернуть tool_calls.
3. Наш код выполняет функцию, добавляет результат в диалог как сообщение с ролью tool.
4. Повторный запрос → модель формулирует финальный ответ с учётом результата.

Ключевые моменты:
- Описание функции — это промпт. От него зависит, насколько точно модель вызовет функцию. Писать так же тщательно, как системный промпт.
- Модель может попросить несколько вызовов за раз (parallel tool calls).
- Аргументы от модели — НЕДОВЕРЕННЫЙ ввод. Валидировать перед выполнением, как любой пользовательский ввод.

Применение: погода, поиск в БД, калькулятор, действия в приложении.
