# Эмбеддинги

Эмбеддинг — вектор чисел (например, 1536 чисел у text-embedding-3-small), представляющий смысл текста. Тексты с похожим смыслом → близкие векторы.

Как мерить близость: косинусное сходство (cosine similarity). 1.0 = идентичные, 0 = не связаны. Евклидово расстояние тоже используют, но косинус — стандарт для текстов.

Свойства, которые запомнил:
- «кошка» и «кот» близки, хотя буквы разные.
- «банк» (финансы) и «банк» (река) — одинаковое слово, но в разных предложениях получит разные векторы, потому что эмбеддинг зависит от контекста предложения.
- Эмбеддинги не объяснимы: нельзя сказать, «что означает 42-е число вектора».

Применение из лекции: семантический поиск, рекомендации, кластеризация, дедупликация.

Моя заметка: для мини-проекта с 5–10 заметками эмбеддинги — оверкилл, хватит поиска по ключевым словам. Но если заметок станет >100, тогда уже имеет смысл.
