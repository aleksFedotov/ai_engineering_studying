# Температура и top_p

Температура — параметр сэмплирования, контролирует «случайность» ответа.

- temperature = 0: модель почти всегда выбирает самый вероятный токен. Ответы детерминированные (но не гарантированно на 100%).
- temperature = 1: стандартное поведение.
- temperature = 2: максимальная случайность, часто бред.

Из лекции: менять одновременно temperature и top_p не рекомендуется — они дублируют друг друга. OpenAI в документации советует крутить что-то одно.

Мои наблюдения из домашки:
- Для чата по заметкам (RAG-стиль) ставлю temperature = 0–0.3: нужна точность, а не креатив.
- Для генерации идей — 0.8–1.0.
- На temperature = 0 модель всё равно может галлюцинировать! Температура влияет на разнообразие, а не на правдивость. Это было неочевидно.

top_p (nucleus sampling): модель рассматривает только токены, суммарная вероятность которых ≤ p. top_p = 0.1 означает «только топ-10% массы вероятности».
