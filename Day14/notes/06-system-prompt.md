# Системный промпт

Системный промпт — сообщение с ролью system, идёт первым и задаёт правила поведения модели на весь диалог.

Что туда класть (чек-лист с лекции):
1. Роль («ты — ассистент, отвечающий по заметкам пользователя»).
2. Границы («отвечай только на основе предоставленных заметок»).
3. Формат ответа («сначала цитата, потом ответ»).
4. Поведение в краевых случаях («если ответа нет в заметках — скажи "не знаю"»).

Приёмы, которые работают (мой опыт из ДЗ):
- Прямой запрет работает лучше мягких формулировок: «НИКОГДА не используй знания вне заметок» > «старайся опираться на заметки».
- Требование цитаты перед ответом сильно снижает галлюцинации: модели сложнее выдумать цитату, и сразу видно, если выдумала.
- Примеры в системном промпте (few-shot) работают лучше абстрактных инструкций.

Антипаттерн: пихать в системный промпт инструкции, которые противоречат друг другу. Модель выберет одну и проигнорирует другую — непредсказуемо какую.
