# Стоимость API

Модель ценообразования OpenAI: платишь за токены, отдельно за вход (input) и выход (output). Output токены заметно дороже input — обычно в 3–4 раза.

Формула стоимости запроса:
cost = (input_tokens × input_price + output_tokens × output_price) / 1_000_000
(цены указаны за миллион токенов)

Откуда брать числа для расчёта: поле usage в ответе API:
- usage.prompt_tokens — вход
- usage.completion_tokens — выход
- usage.total_tokens — сумма (для контроля)

Важно из лекции:
- Системный промпт и подгруженные документы — это ТОЖЕ input токены, платим за них в КАЖДОМ запросе диалога.
- История диалога тоже пересылается каждый раз → длинные диалоги дорожают квадратично (примерно).
- Кэширование промптов (prompt caching) снижает цену повторяющейся части входа, но это уже продвинутая тема.

Моя заметка для мини-проекта: в нашем чате по заметкам заметки — это постоянный «налог» на каждый запрос. Счётчик стоимости должен показывать и стоимость запроса, и накопленную сумму за сессию.
