# Контекстное окно

Контекстное окно — максимальное количество токенов, которое модель видит одновременно (вход + выход вместе).

Цифры с лекции (на момент курса):
- gpt-4o: 128k токенов контекст, до 16k на выход.
- gpt-4o-mini: тоже 128k контекст.
- Старый gpt-3.5-turbo: 16k.

Важные следствия:
1. В контекст входит ВСЁ: системный промпт, история диалога, подгруженные документы и сам ответ модели.
2. «Модель видит окно» ≠ «модель хорошо помнит всё окно». Есть эффект lost in the middle: информацию из середины длинного контекста модель использует хуже, чем из начала и конца.
3. При превышении лимита API возвращает ошибку (context_length_exceeded), её надо обрабатывать.

Моя заметка для мини-проекта: 5–10 заметок — это копейки, всё влезет. Но код обрезки истории диалога всё равно стоит написать сразу, потом будет больнее.
